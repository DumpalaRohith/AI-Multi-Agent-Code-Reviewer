# AI Multi-Agent Code Reviewer

## Overview

AI Multi-Agent Code Reviewer is an intelligent application that analyzes Python code using multiple AI agents working together. Instead of relying on a single LLM response, the application divides responsibilities among specialized agents to review, optimize, and explain code improvements.

The project is built using LangGraph for workflow orchestration, LangChain for LLM integration, Groq as the inference provider, and Streamlit for the web interface.

## Features

- Multi-Agent Architecture
- Reviewer Agent for code analysis
- Optimizer Agent for improving code quality
- Explainer Agent for describing improvements
- LangGraph workflow orchestration
- Groq LLM integration
- Interactive Streamlit interface
- Modular project structure
